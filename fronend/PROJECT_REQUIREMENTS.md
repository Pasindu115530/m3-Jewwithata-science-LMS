Create a modern, colorful, responsive **Science Tuition Class LMS UI** for an individual Science tuition teacher.

Use:

* Next.js App Router
* TypeScript
* Tailwind CSS
* Firebase-ready project structure
* Node.js-compatible architecture
* Reusable React components
* Lucide React icons

This project is **UI design only**. Use realistic mock data. Do not implement real authentication, Firebase database operations, Zoom integration, payment processing, or file uploads.

## Project Concept

This platform belongs to a single Science tuition teacher who conducts:

* Physical Science tuition classes
* Online Zoom classes
* Revision classes
* Theory classes
* Paper classes
* Free lessons
* Assignment activities
* Student progress monitoring

The website should promote the teacher’s tuition classes, provide information to students and parents, and allow registered students to access lessons, classes, assignments, attendance, payments, and announcements.

The teacher should have a separate dashboard to manage students, classes, attendance, assignments, and payment approvals.

Do not design the platform like a school, university, or large academy. It should feel like a professional personal tuition brand operated by one Science teacher.
